# Live static deployment source

This folder contains the static browser deployment published at https://encoded-relay-gux885d.shipstatic.com.

The application uses Preact 10.26.4 and Preact Hooks from esm.sh browser ESM modules. It has no backend, credentials, analytics, or paid API dependencies. The hosted deployment is permanent on the connected free ShipStatic account (no expiry reported by the host).

To update the live copy, deploy the contents of this folder as the site root. Keep the Vite source in ../studio as the framework-development workspace.
